Live in the viewer. `describe-me dev` starts the live preview next to the viewer, on the root and config file the manifest names, and prints its address. The **Live** toggle at the start of the toolbar, the `L` key or `live=1` in the link mounts the selected test the way its arrange phase set it up. Clicks and timers are real. The inspector shows the live status and its reason, each call of a `vi.fn()` prop as an action, the errors the component throws, notices and a Restart button for a fresh start.

- `describe-me dev --no-live` starts the viewer alone. `--root <dir>` points the live preview at another project root, with the config file Vitest picks there.
- A live preview that cannot start leaves the viewer running without Live, and the toggle's tooltip says why.
